# Racket-Kratos-Zeus-Fight
A game made in 2 weeks by some guidance.
Install Racket: Download and install Racket from racket-lang.org.

Download evren.

Keep the Folder Structure: Make sure the game code file (.rkt) and the folders (imaj, ses, Teachpacks) are together in the same folder.

Open in DrRacket: Open the "Kratos-Zeus Fight" file in DrRacket.

Run the Game: Click the "Run" button in the top right corner, then type your start command (like (go)) into the interaction window at the bottom and press Enter.
